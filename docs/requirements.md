# 原始需求

😫多线程批量发送，提高效率,可设置发送频率。
😫自定义内容：支持读取多个HTML内容文件。
😫链接替换：自动替换邮件内容中的链接，支持循环使用多个链接。
😫随机内容插入：可选择性地在HTML中插入随机内容，增加邮件唯一性。
😫代理支持：可配置代理服务器，提高发送成功率。
😫错误处理：详细的错误处理机制，包括连接失败、发送被拒等情况。
😫实时统计：记录发送成功、失败等统计信息，并定期更新状态文件。
😫灵活配置：通过配置文件设置各项参数，如发件人信息、发送限制等。
😫日志记录：详细记录发送过程，支持成功、失败、阻止等多种情况。
😫自动清理：程序结束时自动整理文件。
🔥🔥🔥🔥🔥🔥🔥🔥🔥🔥🔥🔥🔥
该系统设计用于大规模邮件发送，具有高度的可定制性和稳定性。

找合适的渠道可能需要你来考虑了，因为还有成本问题

技术上来说可以做的是：
1. 做一个集群，通过异步消息队列的方式，支持多机器部署，多进程，多线程，批量发送
2. 做个简单的管理后台，实现邮件任务的管理，数据看板

1. 管理号池，每个号池就是配置一些 SMTP
2. 创建邮件任务，上传邮件模板，收件人，选择号池（N个，+权重）
3. 设置发送策略，（发送的并发数量）
4. 看统计报告，错误日志

运维的角度
1. 一键部署
2. 增加服务器资源，扩容发送的服务的副本数量完成扩容


如果考虑自建 mailserver 服务，在加一个 mailserver 的运维


# 整理需求

## 管理后台

### 数据汇总看板

基于 metabase 嵌入到后台页面中

- 号池数量，号池内邮箱数量，邮箱在线状态
- 邮件任务数量
- 邮件发送数量，成功数量，失败数量, 按日统计

### 号池管理

- 添加号池
- 编辑号池
- 删除号池

#### 号池内邮箱管理

- 添加邮箱
- 编辑邮箱
- 删除邮箱

### 邮件服务器配置

- 邮件服务出口 IP 搜集
- 添加邮件域名
- 邮件服务 DNS 配置建议
- 邮件服务当前域名解析状态

### 邮件任务管理

- 创建邮件任务
  - 上传邮件模版 (html, text)
  - 上传收件人列表（csv, excel）
  - 邮件模版支持的变量
    - 随机内容函数
    - 收件人
  - 邮件标题（支持模版变量）
  - 勾选号池
    - 权重
  - 设置发送策略
    - 发送频率
  - 设置任务开始时间
- 编辑邮件任务
- 删除邮件任务（软删除）
- 测试邮件（号池，指定发件人，指定目标邮箱）

### 邮件任务日志

- 查看邮件任务发送日志
- 查看邮件任务发送状态

## API & server

- 实现管理后台数据接口支持。
- 分发任务，按照任务配置，分发任务到 rabbitmq
- 测试邮件，分发任务到消息队列
- DNS 解析状态监控/轮询

## 邮件发送 worker

- 从消息队列 rabbitmq 中获取邮件任务
- 根据邮件任务配置进行邮件发送
- 发送成功或失败后更新邮件任务状态
- 更新邮件任务日志
- 定期汇报出口 IP

> 安装 postfix (worker 容器) 邮件发送使用 postfix 的 sendmail 命令
